The Dilemma

Why We Built Universal PC Remote™

In recent years, remote desktop and control applications have transformed from lightweight local utilities into heavy, cloud-tethered SaaS products. Traditional remote tools now require mandatory cloud accounts, route unencrypted mouse coordinates through overseas relays, impose intrusive monthly subscriptions, and introduce between 80ms and 200ms of lag — even when your phone and laptop are sitting two feet apart on the same home desk.

We believe that basic workstation remote control — moving a cursor, skipping a track, pausing video, typing a note, or stepping through slides — should be instantaneous, private, and fully offline. Universal PC Remote™ by Aniket Akal restores that freedom.

⚡

8ms Micro-Latency

Direct local socket piping bypasses the internet entirely. High-frequency touchpad touch events stream straight from Dart/Flutter to native Win32 input injection within 8 milliseconds.

🔒

Zero-Cloud Guarantee

No account creation, no analytics endpoints, no telemetry pinging, and zero external routing. All UDP discovery beacons and WebSocket frames terminate strictly inside your Wi-Fi router.

🛡️

Cryptographic Pairing

Every pairing session begins with an ephemeral 6-digit challenge code generated locally on the host PC. Persistent authorization uses SHA-256 tokens stored securely on your device.

📦

Zero-Install Companion

The Windows companion runs as a self-contained, portable single-file binary. No installer required, zero registry bloat, and seamlessly docks right into your Windows system tray.

Under the Hood

The Engineering Stack

Universal PC Remote™ is built upon modern, rock-solid engineering foundations designed specifically for extreme responsiveness and low resource overhead:

1

Mobile Client Engine (Google Flutter 3.24+ & Dart)

The mobile application utilizes Flutter's hardware-accelerated Skia/Impeller graphics engine to render trackpads, sliders, and button decks at smooth 60fps/120fps display refresh rates. Gesture recognizers deliver sub-pixel pointer updates and multi-touch scroll tracking with zero frame drops.

2

Windows Companion Core (Microsoft .NET 8 C#)

The companion is built on .NET 8's high-throughput asynchronous I/O runtime. It leverages System.Net.WebSockets for zero-allocation event parsing and direct P/Invoke calls into Win32 SendInput and media virtual keycodes (VK_MEDIA_PLAY_PAUSE, VK_VOLUME_UP, etc.), ensuring immediate microsecond execution.

3

Local Discovery Beacon Protocol (UDP Broadcast)

When you launch the mobile client, it broadcasts a lightweight UDP query on port 51235 across the local subnet. The Windows companion automatically replies with its friendly hostname, active IP, and listening port — removing the need to memorize or look up IP addresses manually.
