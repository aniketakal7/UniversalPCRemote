Privacy Policy

Effective Date: October 2026 • Universal PC Remote™ by Aniket Akal is engineered from the ground up as a zero-cloud, 100% private, peer-to-peer software system.

Zero Cloud Relay Zero Telemetry Zero Third-Party SDKs No User Accounts

1. The Zero-Cloud Principle

Universal PC Remote™ does not operate external cloud servers, relay brokers, or hosted databases. All communication between the Android mobile client and the Windows PC companion occurs exclusively over your local Area Network (LAN), Wi-Fi, or direct mobile hotspot.

At no point are your keystrokes, pointer movements, device identifiers, or clipboard contents transmitted over the public internet or stored on remote infrastructure.

2. Information We Do Not Collect

Unlike conventional remote desktop utilities, Universal PC Remote™ collects absolutely no personal data:

  • No Personal Identifiers: We do not ask for or collect names, email addresses, phone numbers, or passwords.
  • No Telemetry or Analytics: We include no crash reporting SDKs (such as Firebase, Sentry, or AppCenter), no behavioral tracking scripts, and no marketing beacons.
  • No Input Logging: Keystrokes, mouse clicks, and touchpad coordinates are dispatched in real-time straight to the operating system's input pipeline and are discarded immediately after injection.

3. Mobile Device Permissions (Android)

To perform low-latency remote control over local Wi-Fi, the Android application requests only the minimal set of strictly technical permissions:

Permission Technical Purpose Data Handling
INTERNET & ACCESS_NETWORK_STATE Allows opening TCP/WebSocket sockets on local Wi-Fi to communicate with your PC companion. Local socket only; zero outbound internet requests.
CHANGE_WIFI_MULTICAST_STATE Allows broadcasting and receiving UDP discovery beacons on port 51235 to auto-locate your PC. Processed in memory; never logged.
FOREGROUND_SERVICE Keeps your remote session active without the operating system putting the network socket to sleep. Displays an active session notification; terminates upon disconnect.
VIBRATE Provides subtle haptic click and toggle feedback when tapping trackpad buttons or media transport keys. Hardware actuator only; no data stored.
CAMERA (Optional) Used strictly if you choose to scan the direct connection QR code from the Windows screen. Processed locally via camera stream; zero images saved or uploaded.

4. Windows Companion Security & Privileges

The Windows companion is a self-contained portable executable. It does not install background services, create registry startup keys without explicit permission, or inject kernel drivers:

  • Input Injection: Uses standard Win32 SendInput API calls to simulate mouse movements and keyboard events strictly when authenticated packets are received from your paired phone.
  • Network Ports: Listens exclusively on local TCP port 51234 and UDP port 51235. It does not open firewall holes to the external internet or request UPnP router port forwarding.
  • Device Trust Keystore: Stores authorized device pairing tokens in a lightweight local JSON file in your user directory. You can revoke any paired device with one click at any time.

5. Clipboard Transfer Security

Universal PC Remote™ includes an optional two-way clipboard synchronization tool. When you explicitly trigger clipboard sharing, the text payload is transmitted directly over your local encrypted/authenticated WebSocket session. Clipboard contents are never logged, never cached to disk, and never analyzed.

6. Cookies and Web Tracking

This website (universalpcremote.pages.dev) uses zero cookies, zero session trackers, and zero third-party advertising or analytics scripts. Your visits are completely private.
