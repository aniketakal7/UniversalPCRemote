# Universal PC Remote™ by Aniket Akal

A production-ready, open-source, zero-cloud PC remote control system built with Flutter and .NET 8.

## Features
- **Zero Cloud / 100% Local Network**: Completely operates over local Wi-Fi. No internet access required.
- **Low Latency Input Control**:
  - Touchpad with relative pointer tracking, clicks, double click, dragging, and 2-finger scrolling.
  - Full virtual keyboard, modifier keys (Ctrl, Alt, Shift, Win), function keys, and text injection.
- **Media Controls**: Real Windows media controls (Play/Pause, Next, Previous, Volume Up/Down, Mute).
- **System Controls**: Lock workstation, Sleep, Shutdown, Restart (with explicit confirmation on phone).
- **Clipboard Sync**: Secure two-way text clipboard transfer.
- **Application Remotes & Safe Macros**: Pre-built remotes (VLC, Media Players, Browser, Presentation) and structured macro runner.
- **Local Network Discovery**: UDP discovery beacon auto-locates your PC on the local network.
- **Cryptographic Device Pairing**: Safe 6-digit PIN pairing with cryptographic token exchange and revocation.
- **Diagnostics**: Built-in test suite verifying all subsystems.

## Requirements
- **Windows PC**: Windows 10/11 x64, .NET 8 SDK or Runtime.
- **Android Phone**: Android 8.0+, Flutter 3.24+.
